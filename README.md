# Gemini Chat

Gemini API bilan gaplashadigan shaxsiy chat sahifasi. Bitta fayl: `index.html`.

- Gemini'ga brauzerning o'zi murojaat qiladi.
- Chatlar shu repo'da emas, alohida **private** repo'da (`chats/*.json`) saqlanadi.
- Gemini API key va GitHub token faqat brauzerning `localStorage`'ida turadi. Ularni kodga yoki repo'ga yozmang.

Sozlash: sahifada "Sozlama" tugmasini bosing.
